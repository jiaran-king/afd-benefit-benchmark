# 公开材料范围

本版公开实验方法、固定参数、必要补丁与执行器、正式报告、36,312 请求的数值字段、72,624 条准入/完成事件、逐 DIE/域容量、冻结输入索引和单独标注的诊断。原始会话及正式冻结负载作为独立的 [数据集 Release](https://github.com/jiaran-king/afd-benefit-benchmark/releases/tag/datasets-20261012-v1) 附件发布。

两份数据正文均无删改，分别记录压缩包和原文件 SHA256。原会话的 7 处私钥格式内容已核对为有明确测试用途上下文，见 [核查记录](../datasets/raw/content-review.md)；此前“样例未确认、输入需另行取得”的说明已被本次核查与发布替代。

模型权重、匹配的 native 二进制和构建树、完整机器环境、鉴权文件及原始集群控制日志不随此次发布。匹配运行环境仍需另行准备；仅 clone 仓库不等于已经具备原性能环境。数值复核不需要下载数据正文，设备复现可直接取得 Release 中的精确冻结文件。

scripts/check_publication.py 检查 Git 中的整理材料：文本与压缩 CSV 的高风险凭据格式、内网地址、原工作区路径、文件类型、链接和来源哈希。Release 原始数据单独按其文件身份和上述测试内容核对；该脚本不把已审阅的数据正文按“无私钥标记”的规则扫描，也不把哈希核对描述为全面内容审计。

所有新脚本保持不覆盖旧 run、不自动重试、不静默修改参数。完整环境证据可在私有复现目录保存；未经筛选的复现输出不要直接 git add。
