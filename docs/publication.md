# 公开材料范围

本版公开实验方法、固定参数、必要补丁与执行器、正式报告、36,312 请求的数值字段、72,624 条准入/完成事件、逐 DIE/域容量、冻结输入索引和单独标注的诊断。

不公开原始 conversation JSON、可逆 token payload、模型权重、完整机器环境、鉴权文件、内部地址或原始集群控制日志。原会话发现 7 处私钥格式标记，是否为样例未确认；保留原输入而不自动公开，避免改变负载来通过扫描。

原始输入、匹配的 native 二进制及构建树必须另行取得。仓库没有提供这些资产的公共下载链接，也没有声称仅 clone 即能启动原性能环境。公开数值复核则不依赖这些资产。

发布前检查包括文本与压缩 CSV 中的高风险凭据格式、内网地址、原工作区路径、文件类型和链接；这种检查不能证明所有潜在敏感内容都不存在，因此采用明确字段筛选而不是只依赖正则扫描。

所有新脚本保持不覆盖旧 run、不自动重试、不静默修改参数。完整环境证据可在私有复现目录保存；未经筛选的复现输出不要直接 git add。
